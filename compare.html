How each layer mixes the tokens

In the simulator every layer uses full attention: each token looks at all the previous ones, which gets expensive with long contexts. Recent models mix in cheaper layers: local attention over a short window, linear attention or state-space layers that keep a fixed-size memory instead of a growing KV-cache, and sparse attention that first selects the relevant tokens.

Vocabulary

Vocabularies have grown from 50k tokens (GPT-2) to 100k–260k, to cover many languages and code with fewer tokens. The embedding tables (vocabulary × d_model, twice when input and output are not shared) are a large part of small models and a tiny part of large ones: hover a bar to see it.
