What each page shows

  • Prediction, step by step: tokenizer → embeddings → every layer (LayerNorm, Q/K/V, each attention head, feed-forward, residuals) → logits → sampling, for the first tokens generated after the prompt; from the second token on, the KV-cache is used.
  • Training step: loss, backpropagation layer by layer, gradients, clipping and the AdamW update, repeated on the same sequence.
  • Weights: every learned matrix (W_E, W_Q, W_K, W_V, W_O, the FFN, W_U…) with what it does.
